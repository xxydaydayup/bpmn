# 设计器样式使用独立附属配置

**Status: accepted**

设计器的全局主题和节点/连线级样式只影响编辑器展示，不写入 BPMN XML；元素级覆盖保存在独立的样式附属 JSON 中，并按流程设计稿版本与 BPMN 元素 ID 关联。导出时以 BPMN 与 JSON 配套文件交付，主题只提供预设主题和固定 token，样式工具从顶部工具栏进入并支持多选批量操作。这样保留 Camunda 7 和其他 BPMN 工具的 XML 互操作性，同时允许产品恢复品牌主题和局部视觉调整；缺失样式时回退到主题默认值，样式附属配置不作为部署产物。

**Considered Options**

- 直接写入 BPMN DI：可被部分工具读取，但会把展示选择带入执行文件，并增加 `bioc`/扩展命名空间兼容风险。
- 只保留运行时主题：互操作性最好，但无法恢复用户对单个元素的视觉调整。
- 使用独立样式附属配置：增加版本关联和 ID 迁移成本，但将展示状态与流程语义隔离，采用此方案。

**Consequences**

- 需要为流程版本保存样式附属 JSON，并在复制、导入、元素 ID 变化时处理关联关系。
- 画布 Renderer 读取“主题默认值 + 元素覆盖”，导出 BPMN XML 时忽略样式附属配置。
- 导出、导入和模板复制需要同时处理 BPMN 文件与配套 JSON；只提供 BPMN 文件时使用预设主题默认值。
- 网格、吸附、对齐、分布和缩略图由顶部工具栏控制，批量样式操作只作用于当前选择集。
- `bpmn-js-color-picker` 的默认持久化语义不直接适用；若引入，只能复用其 UI 或适配为 sidecar 写入。

# 业务流程预览共用渲染能力，提供组件和 iframe 页面

**Status: accepted**（2026-11-23，用户要求按已确认的 workflow-preview 规格实施）

已发布任务模板、运行实例和历史实例共用设计器包的 `WorkflowPreview`。组件只接收单向 `displayJson`、展示元信息和节点状态，不持有 API、鉴权或编辑能力；宿主负责取数、错误及 BPMN XML 备用入口。独立预览避免完整设计器的编辑状态、编译和发布职责进入查看流程，沿用 ADR-0005 的模型与宿主边界。

业务模型优先，保留可靠坐标与尺寸；缺少布局时仅为内部副本生成临时布局。未知节点展示名称、原类型与能力提示，不展示未知业务字段；空/重复定义 ID、悬空连线和其他无法可靠绘制的结构清图报错。子流程只展示外层及步骤数。模型缺失或无效时，用户可显式查看同一快照的 BPMN XML 备用图，不从 XML 反推模型。

实例以自己的 `processDefinitionId` 为唯一版本匹配依据，通过可见模板历史索引找到精确版本并核对详情。匹配失败时只能使用相同定义 ID 的引擎 XML，禁止用最新模板解释旧实例。当前活动树只展示当前活动；已结束实例只按历史接口明确返回的完成/取消记录标记节点，不推断顺序流执行路径。

iframe 使用无导航的 `/workflow-preview`，一次接受单值 `templateKey` 或 `processInstanceId` 并自行取数，支持应用/API 子路径。基本接入通过更新 iframe 地址完成，不要求 postMessage。默认由业务系统同源代理沿用真实访问者会话，后端逐项校验用户、租户、模板、实例和定义访问权限；定位标识不构成授权。嵌入来源由部署允许列表与 HTTP CSP `frame-ancestors` 控制，不接收 URL 令牌、任意 API 或来源授权。

仓库交付前端、请求契约和部署示例；生产身份代理、租户权限与 CSP 由实际网关/部署验收。组件及模拟接口测试不等于生产授权通过。实现与接入见 [预览说明](../workflow-preview.md) 和 [嵌入指南](../workflow-preview-embedding.md)。

# Domain Docs

本仓库采用 single-context 布局：根目录的 `CONTEXT.md` 保存领域术语与模型，`docs/adr/` 保存架构决策。

## 按需读取

- 探索代码中的业务概念前，读取根目录 `CONTEXT.md`。
- 涉及架构或行为取舍时，读取 `docs/adr/` 中与当前工作相关的决策。
- 文件或目录尚不存在时，直接继续任务；无需报告缺失或提前创建占位文件。`domain-modeling` 在术语或决策确定后按需创建它们。

## 术语与决策

- 工单标题、方案、假设和测试中的领域概念沿用 `CONTEXT.md` 已定义的名称。
- 遇到术语表未包含的概念，先检查是否已有对应术语；确有缺口时，记录供 `domain-modeling` 补充。
- 建议与已有 ADR 冲突时，明确引用 ADR 编号并说明重新讨论的理由。

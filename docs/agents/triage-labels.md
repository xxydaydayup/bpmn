# Triage Labels

工程技能中的五个标准分诊角色使用以下默认值：

| 标准角色 | 本仓库状态值 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格明确，可由代理实施 |
| `ready-for-human` | `ready-for-human` | 需要人工实施或判断 |
| `wontfix` | `wontfix` | 决定不处理 |

技能提及分诊角色时，使用表中对应状态值；文件中的存储位置遵循 [事项跟踪约定](./issue-tracker.md)。

后续需要自定义名称时，修改“本仓库状态值”列，保留标准角色列供技能映射。

# Tabler Icons

These unmodified outline SVG files come from `@tabler/icons@3.47.0`, downloaded from the official npm registry on 2026-09-20. They are distributed under the MIT license in `LICENSE.txt`.

Source: https://github.com/tabler/tabler-icons

The application imports only mapped icons through `src/bpmn/icons.ts`. Adding or replacing a mapping changes the node library, canvas cards, or controls without changing BPMN semantics.
